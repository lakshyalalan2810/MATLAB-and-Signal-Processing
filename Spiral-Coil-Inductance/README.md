# Spiral Coil Inductance Analysis

MATLAB modeling and analysis of spiral coil inductance for RF and wireless applications.

## Project Structure

- `code/`: MATLAB source code files.
- `images/`: Simulation plots and figures.
- `report.pdf`: Project report document.

## Description

This project provides MATLAB scripts to model and analyze the inductance of spiral coils (such as planar spiral inductors). It calculates key electrical parameters useful for RF, antenna design, and wireless power transfer applications.
