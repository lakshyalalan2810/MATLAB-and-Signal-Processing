# MATLAB and Signal Processing Projects

A collection of MATLAB-based projects developed during coursework and independent study in signal processing, wireless communications, random processes, and electromagnetics.

## Projects

### 1. Adaptive AGC for Superheterodyne Receiver
Simulation of a PI-controlled Automatic Gain Control (AGC) system under AWGN and Rayleigh fading channels.

### 2. Phase Optimization in Reconfigurable Intelligent Surfaces (RIS)
MATLAB simulation of RIS-assisted wireless communication with optimized phase control for signal enhancement.

### 3. Signal Recovery from AWGN using Moving Average Filter
Implementation and analysis of a Moving Average filter for noise suppression using FFT, PSD, SNR, and MSE metrics.

### 4. Spiral Coil Inductance Analysis
MATLAB modeling and analysis of spiral coil inductance for RF and wireless applications.

## Tools Used

- MATLAB
- Signal Processing Toolbox
- Communications Toolbox
- Numerical Modeling
- Monte Carlo Simulation
