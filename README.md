# Projects

## 1. Adaptive Automatic Gain Control for Superheterodyne Receiver

### Overview

Designed and simulated an adaptive Automatic Gain Control (AGC) system for a Superheterodyne Receiver using MATLAB.

The project implements a Variable Gain Amplifier (VGA), envelope detector, adaptive gain control logic, and PI-based feedback controller to maintain stable receiver output under varying channel conditions.

### Key Features

- PI-Based AGC Controller
- Adaptive Attack and Decay Mechanism
- AWGN Channel Modeling
- Rayleigh Fading Simulation
- Receiver Stability Analysis
- Gain Regulation and Control

### Technologies

- MATLAB
- Control Systems
- Communication Systems
- Signal Processing

### Applications

- Wireless Receivers
- SDR Systems
- RF Front Ends
- Cellular Communication

## 2. Phase Optimization in Reconfigurable Intelligent Surfaces (RIS)

## 3. Signal Recovery from AWGN using Moving Average Filtering

### Overview

Implemented a Moving Average (MA) filter for recovering signals corrupted by Additive White Gaussian Noise (AWGN).

The system evaluates noise suppression performance using FFT, PSD, autocorrelation analysis, SNR improvement, and Mean Squared Error (MSE) reduction.

### Key Features

- AWGN Modeling
- Moving Average Filtering
- FFT Analysis
- Power Spectral Density (PSD)
- Statistical Signal Analysis
- LTI System Characterization

### Technologies

- MATLAB
- DSP
- Random Processes
- FIR Filtering

### Applications

- Communication Systems
- Sensor Data Processing
- Biomedical Signals
- Noise Reduction Systems

## 4. Planar Spiral Coil Inductance Analysis

### Overview

Developed a MATLAB simulation framework for analyzing planar spiral coil inductance and visualizing magnetic field distribution.
