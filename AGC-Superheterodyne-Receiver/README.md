# Adaptive AGC for Superheterodyne Receiver

Simulation of a PI-controlled Automatic Gain Control (AGC) system under AWGN and Rayleigh fading channels.

## Project Structure

- `code/`: MATLAB source code files.
- `images/`: Simulation plots and figures.
- `report.pdf`: Project report document.

## Description

This project simulates a closed-loop Automatic Gain Control (AGC) system using a Proportional-Integral (PI) controller. The performance is evaluated under AWGN and Rayleigh fading channel conditions.
